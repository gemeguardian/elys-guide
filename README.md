# Elys.guide

Интерактивное руководство пользователя для [Elys Userbot](https://github.com/ZavozDevs/Elys).

Статичный сайт: чистые HTML, CSS и JavaScript. Ни одного внешнего запроса, ни одного байта фреймворка, ни одного шага сборки.

## О чём гайд

13 глав — от «что такое юзербот и почему это риск» до написания своих модулей на loader API.

| № | Глава |
|---|--------|
| 00 | Обзор |
| 01 | Перед стартом — требования, `api_id`, риски |
| 02 | Установка — Debian, Fedora, Arch, Termux, Docker |
| 03 | Первый запуск — авторизация и инлайн-бот |
| 04 | Инлайн и бот — формы, галереи, списки |
| 05 | Модули — `dlmod`, репозитории, пресеты |
| 06 | Конфигурация — префикс, алиасы, база, NoNick |
| 07 | Безопасность — уровни доступа, `tsec`, владельцы |
| 08 | Обновления — `update`, `branch`, `rollback` |
| 09 | Бэкапы — `backupall`, `restoredb`, автобэкап |
| 10 | Справочник команд — все команды ядра с живым фильтром |
| 11 | Свои модули — loader API, ватчеры, конфиг |
| 12 | FAQ и ремонт |

## Фронтенд

Сайт сделан тактильным осознанно — каждое действие даёт ответ.

- **Собственный курсор** с инерционным кольцом, реагирующим на тип цели под ним
- **3D-тильт на пружине** для карточек и главной иллюстрации
- **Ripple + `navigator.vibrate`** — тактильный отклик на телефоне
- **Живой canvas** в герое — сеть узлов, разбегающаяся от курсора
- **Авторские SVG-рисунки**: сигил, орбиты, терминал с кареткой и QR, сеть инлайн-API, щит безопасности, стек бэкапов — всё анимировано через `stroke-dasharray`
- **Командная палитра** на <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> / <kbd>/</kbd> с нечётким поиском по главам и командам
- **Конструктор установки** — выбираете ОС и флаги, получаете готовый скрипт с подсветкой
- **На мобилках**: нижний док с пружинным индикатором, меню-шторка с drag-to-dismiss, свайпы между главами, `env(safe-area-inset-*)`
- **Две темы**, следует системной и запоминает выбор
- Полные фоллбеки на `prefers-reduced-motion`, клавиатурная навигация, skip-link, печатные стили

### Горячие клавиши

| Клавиша | Действие |
|---------|-----------|
| `⌘K` / `Ctrl+K` / `/` | Командная палитра |
| `j` / `→` | Следующая глава |
| `k` / `←` | Предыдущая глава |
| `t` | Переключить тему |
| `Esc` | Закрыть палитру или меню |

## Запуск локально

```bash
git clone https://github.com/gemeguardian/elys-guide
cd elys-guide
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Можно и просто открыть `index.html` файлом — внешних зависимостей нет.
