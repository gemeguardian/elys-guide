Коротко: что это такое

Elys — это юзербот: программа, которая заходит в Telegram как вы, а не как обычный бот. Она читает ваши собственные сообщения, видит в них команды вроде .ping и выполняет их. Ветка рода: Hikka → Heroku → Elys.

Команды из любого чата

Пишете .help в своём сообщении — бот его перехватывает и редактирует в ответ. Собеседник видит только результат.

Модульность

Ядро маленькое. Всё остальное — .dlmod. Совместимо с модулями FTG, Hikka и Heroku.

Слои безопасности

Группы доступа, таргетированные правила с таймером и анти-флуд для Telegram API.

Бэкапы и мультиакк

Автоматические бэкапы базы и модулей, несколько аккаунтов на одном сервере.

Маршрут новичка

  1. 1Подготовкасервер, Python, api_id
  2. 2Установкаодна команда в терминал
  3. 3АвторизацияQR или номер телефона
  4. 4Модулиставим то, ради чего всё
  5. 5Защитачтобы не увели аккаунт

Прочитайте один раз и запомните

Юзербот — это полный доступ к вашему аккаунту. Чужой модуль с .dlmod может слить сессию. Ставьте код только из репозиториев, которым доверяете, и держите .api_fw_protection включённой. Telegram может ограничить аккаунт за агрессивную автоматизацию — риск на вас.

01

Что нужно перед стартом

Три вещи: железо, Python и ключи Telegram. Минут пять работы.

Где будет жить бот

Юзерботу нужен компьютер, который не выключается. Выключили ноут — бот умёр.

VPS · рекомендуется

Любой дешёвый Linux-сервер. 1 vCPU / 1 GB RAM хватает с запасом. Ubuntu 22.04+ — самый беспроблемный вариант.

Телефон · для пробы

Android + UserLAnd. Работает, но система убьёт процесс в фоне. Не для постоянной жизни.

Windows · через WSL

Только WSL2 с Ubuntu. Напрямую на Windows проект не рассчитан и может вести себя странно.

Требования из кода

  • Python 3.10 или выше. На 3.9 запуск оборвётся с явной ошибкой — это проверка в __main__.py.
  • git — без него не будет работать .update, .rollback и определение ветки.
  • Системные библиотеки для Pillow и медиа: libjpeg, libwebp, libffi, ffmpeg, imagemagick. Скрипт install.sh ставит их сам.
  • Не root. Под root бот ругается и требует флаг --root либо слово force_insecure.

API_ID и API_HASH

Это ключи приложения Telegram. Без них клиент не подключится.

  1. 1
    Откройте my.telegram.org/apps

    Войдите по номеру телефона, код придёт в сам Telegram.

  2. 2
    Создайте приложение

    Название и короткое имя — любые. Платформа: Desktop.

  3. 3
    Скопируйте оба значения

    Они понадобятся при первом запуске и лягут в config.json рядом с проектом.

Никогда не показывайте скрин с api_hash и не кладите config.json и *.session в публичный репозиторий. Это равносильно отдаче аккаунта.

Что появится на диске

Elys/
elys/ядро: диспетчер, загрузчик, inline, базовые модули
loaded_modules/всё, что вы ставите через .dlmod
config.jsonapi_id / api_hash
*.sessionваш ключ от Telegram — секрет
.venv/изолированное окружение Python

02

Установка

Выберите среду — конструктор соберёт команду под ваш случай.

Конструктор команды

тыкай варианты
bash — ubuntu

Что делает каждая строка

apt install git python3ставим инструменты, без которых ничего не поедет
git clone …/Elysскачиваем исходники в папку Elys
python3 -m venv .venvсоздаём отдельное окружение, чтобы не ломать системный Python
source .venv/bin/activateвходим в это окружение. Нужно делать каждый раз после перезахода в SSH
pip install -r requirements.txtставим зависимости: elystl, Pillow, aiohttp и прочее
python3 -m elysзапуск. Запускать только как пакет, не python3 elys/main.py

Флаги запуска

Всё из реального разбора аргументов в __main__.py и main.py.

ФлагЧто делает
--rootразрешает запуск под root без вопросов
-w / --wipeудаляет сессии, базы, конфиги и loaded_modules. Спросит подтверждение
--no-gitне трогать git вообще. Ветка берётся из ELYS_BRANCH
--data-root PATHхранить данные в другой папке
--type-proxyввести прокси при старте (MTProxy / SOCKS)

Чтобы не падал после выхода из SSH

Закрыли терминал — процесс убит. Нужен screen или systemd.

screen — быстрый способ
sudo apt install screen -y
screen -S elys
cd ~/Elys && source .venv/bin/activate && python3 -m elys
# отцепиться: Ctrl+A, затем D
# вернуться:  screen -r elys
systemd — правильный способ
sudo tee /etc/systemd/system/elys.service >/dev/null <<'EOF'
[Unit]
Description=Elys Userbot
After=network-online.target

[Service]
Type=simple
User=%i
WorkingDirectory=/home/%i/Elys
ExecStart=/home/%i/Elys/.venv/bin/python -m elys
Restart=always
RestartSec=8

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now elys@$USER
journalctl -u elys@$USER -f
Важно: первый запуск сделайте руками в терминале — нужно ввести ключи и код авторизации. Сервис включайте после.
НазадПодготовка ДальшеПервый запуск
03

Первый запуск

Самый волнительный шаг. Здесь бот знакомится с вашим аккаунтом.

Сценарий по шагам

  1. 1
    Ввод api_id и api_hash

    Бот спросит их один раз и сохранит в config.json.

  2. 2
    Способ входа

    QR-код или номер телефона. QR — быстрее: Telegram → Настройки → Устройства → Подключить устройство.

  3. 3
    Код и пароль 2FA

    Если включён облачный пароль — введите его. На экране он не отображается — это нормально.

  4. 4
    Создание inline-бота

    Elys сам пишет @BotFather и делает вашего личного бота-помощника.

  5. 5
    Готово

    Напишите себе в «Избранное» .ping. Ответил — живёт.

Префикс команд

По умолчанию — точка: .help. Если она мешает, меняется одной командой.

.setprefix !теперь все команды через !
Забыли префикс? Он лежит в базе. Откройте своего inline-бота в ЛС — он покажет текущие настройки, или смотрите файл базы в корне проекта.

Запуск под root

Код отказывается работать от root по умолчанию — и это правильно. Если альтернативы нет:

обход проверки root
python3 -m elys --root
# либо постоянно — файл-маркер рядом с проектом:
touch force_insecure
# или полное отключение sudo-логики:
touch no_sudo

Лучше создать отдельного пользователя:

безопасный вариант
adduser elys
usermod -aG sudo elys
su - elys

04

Inline-бот и справка

Кнопки, галереи и формы в Telegram работают именно через него.

Зачем он нужен

Аккаунт человека не умеет рисовать кнопки под сообщением — это может только бот. Поэтому Elys при установке создаёт себе собственного бота и общается с ним изнутри. Современный .help без inline будет выглядеть как простой текст.

Сменить юзернейм бота
.ch_elys_bot <username>

Полезно, если сгенерировался некрасивый автоматический ник.

Привязать своего бота
.ch_bot_token <token>

Если у вас уже есть готовый бот с нужным именем и аватаркой.

Как читать .help

.helpсписок всех модулей с количеством команд
.help Loaderсправка по конкретному модулю с описанием каждой команды
.help dlmodможно искать по имени команды, не только модуля
.helphide <модуль>скрыть модуль из справки — чтобы не светить лишнее в чатах
.supportссылка на чат поддержки

Обозначения в справке

🔹
Обычная команда

вызывается текстом в чате

🔘
Inline-команда

вызывается через @ваш_бот запрос

👁
Ватчер

реагирует на сообщения без команды

🔒
Ограниченный доступ

только владелец или назначенные группы

05

Модули и репозитории

Основная причина, по которой юзерботы вообще ставят.

Ставим модуль

.dlmod <имя>из подключённых репозиториев по короткому имени
.dlmod <url>напрямую по ссылке на .py
.dlmodбез аргументов — покажет список доступных модулей
.lm в ответ на файлустановить присланный файл модуля
.ulm <имя>удалить модуль
.ml <имя>прислать исходный файл установленного модуля
.clearmodulesснести все сторонние модули сразу
.dlmallскачать всё из репозитория. Очень плохая идея без нужды

Свои репозитории

Репозиторий — это адрес, где лежат .py-файлы и индекс. Можно добавить свои.

.addrepo <url>подключить источник модулей
.delrepo <url>отключить его
Любой модуль — это произвольный Python-код с полным доступом к вашей сессии. Незнакомый репозиторий = незнакомый человек с ключами от вашего Telegram.

Пресеты и наборы

Пресет — готовый список модулей, чтобы после переустановки восстановить сборку одной командой.

.presetsсписок доступных пресетов
.lp <имя>установить всё из пресета
.af <папка>добавить текущие модули в свою папку
.fl <папка>загрузить всё из папки
.rff <папка>выкинуть модуль из папки
.la / .alсохранить и восстановить набор алиасов

Выключить без удаления

.togglecmd <команда>отключить одну команду, модуль останётся
.togglemod <модуль>отключить модуль целиком
.clearmodule <модуль>очистить его данные в базе — сброс настроек
.watchers / .watcherсписок и вкл/выкл отдельных ватчеров

06

Конфиг и настройки

Где крутить ручки ядра и каждого модуля.

Два разных места

.config

Настройки модулей. Открывается интерактивное меню с кнопками. Есть вариант .fconfig — то же, но принудительно текстом.

.settings

Настройки самого юзербота: ник-режимы, ватчеры, служебные переключатели.

Алиасы — свои имена команд

Если надоело писать длинное название — сделайте короткое.

пример
.addalias p ping        # теперь .p работает как .ping
.aliases                # посмотреть все алиасы
.delalias p             # удалить
.la                     # сохранить набор в файл

Режим без ника (NoNick)

Когда вывод команд не должен выдавать юзербот подписью.

.nonickuserдля конкретного человека
.nonickchatдля чата
.nonickcmdдля одной команды
.nonickusers · .nonickchats · .nonickcmdsпосмотреть текущие списки

Чёрные списки

.blacklistбот перестанёт работать в этом чате
.unblacklistвернуть чат
.blacklistuserигнорировать конкретного пользователя
.unblacklistuserснять игнор

Язык интерфейса

.setlang ruв комплекте есть ru, en, de, jp, ua и пара шуточных паков
.dllangpack <url>подключить свой языковой пакет
.tr <текст>переводчик как бонус

07

Безопасность

Самая важная глава во всём гайде. Прочтите целиком.

Уровни доступа

Каждая команда имеет набор разрешённых ролей. Меняется через .security.

УровеньКто это
ownerвы и те, кого вы добавили в владельцы
group_ownerсоздатель чата, где вызвана команда
group_adminлюбой админ чата. Есть точечные варианты: _add_admins, _ban_users, _delete_messages, _change_info, _pin_messages, _invite_users
group_memberлюбой участник чата
pmтолько в личных сообщениях
everyoneвсе. Опасно, включать только осознанно

Группы безопасности

Вместо того чтобы выдавать права каждому человеку по отдельности, собираете группу и даёте права ей.

типовой сценарий
.newsgroup friends          # создать группу
.sgroupadd friends @user    # добавить человека
.sgroup friends ping        # разрешить группе команду
.sgroups                    # посмотреть все группы
.sgroupdel friends @user    # выкинуть
.delsgroup friends          # удалить группу

Таргетированные правила (tsec)

Самый точный инструмент: выдать одному человеку одну команду и ограничить временем.

.tsecсписок всех активных правил
.tsec @user pingвыдать доступ к команде
.tsec @user ping 1hто же, но на час — потом право сгорит
.tsecrm @userотобрать всё у конкретного человека
.tsecclrобнулить все таргетированные правила

Владельцы и inline

.owneradd · .ownerrm · .ownerlistкто считается владельцем юзербота
.inlinesecкому можно жать кнопки ваших сообщений
.querysecкому можно вызывать вашего inline-бота
Добавляя второго владельца, вы даёте ему практически свой аккаунт: ему станет доступен .terminal и .e.

Анти-флуд Telegram API

Модуль APILimiter следит, чтобы кривой модуль не заспамил Telegram запросами и не привёз вам блокировку.

.api_fw_protectionнастройка порогов защиты. Не отключать
.suspend_api_protect <сек>временно притушить защиту, если она мешает легальной задаче

Короткий чек-лист гигиены

  • Не ставьте модули из личных сообщений от незнакомцев — даже «проверенные другом».
  • Перед .dlmod по ссылке откройте файл и поищите eval, exec, requests.post, чтение *.session.
  • Включите облачный пароль 2FA в Telegram.
  • Держите .terminal и .e только на owner.
  • Периодически смотрите активные сессии в настройках Telegram.
  • Ставьте юзербот не на основной аккаунт, если боитесь его потерять.

Обновления и ветки

Как жить на свежей версии и не сломать сборку.

.updateподтянуть изменения и перезапуститься
.restartперезапуск без обновления
.branch <имя>переключиться на другую ветку репозитория
.rollbackоткатиться на предыдущий коммит, если обновление сломало всё
.changelogсписок изменений
.autoupdateавтоматическое обновление. На продакшене лучше держать выключенным
.sourceссылка на исходный код
.ubstopостановить юзербот полностью
.installationссылка на инструкцию по установке
.uninstall_elysснос юзербота с данными. Необратимо

Если после обновления не запускается

  1. 1
    Посмотрите лог

    Запуск вручную: ошибка будет в терминале последними строками.

  2. 2
    Обновите зависимости

    pip install -r requirements.txt --upgrade — половина проблем именно тут.

  3. 3
    Снесите подозрительный модуль

    Удалите файл из loaded_modules/ и запустите снова.

  4. 4
    Откат

    git log --oneline -n 5, затем git checkout <хеш> или .rollback.

Диагностика

.pingжив ли бот и какова задержка
.logs <уровень>прислать логи: .logs error, .logs debug
.clearlogsочистить буфер логов
.dumpтехнические данные сообщения — незаменимо при отладке модулей
.info / .ubinfoверсия, ветка, аптайм
.setinfo <текст>своё оформление карточки .info
.terminal <cmd>выполнить команду оболочки прямо из Telegram
.e <python>выполнить Python-код в контексте юзербота

09

Бэкапы и аккаунты

Страховка от «упал сервер и всё пропало».

Команды бэкапа

.backupallвсё сразу — база плюс модули
.restoreallвосстановить всё из архива
.backupdb / .restoredbтолько база настроек
.backupmods / .restoremodsтолько список и файлы модулей
.set_backup_period <часы>автобэкап с заданной периодичностью
Разумный дефолт: .set_backup_period 24. Архивы приходят в «Избранное» — там их никто кроме вас не видит.

Несколько аккаунтов

Один процесс может вести несколько сессий.

.addaccдобавить аккаунт — пройдёт такая же авторизация
.switchaccпереключиться между аккаунтами

Бэкап руками

что копировать с сервера
cd ~/Elys
tar czf ~/elys-backup-$(date +%F).tar.gz \
  config.json *.session loaded_modules/ *.db
# забрать на свою машину:
# scp user@host:~/elys-backup-*.tar.gz .
В архиве есть .session — это вход в ваш Telegram без пароля. Не заливайте его в чаты и в облака без шифрования.

11

Пишем свой модуль

Минимальный рабочий скелет и всё API, которое реально есть.

Минимальный модуль

hello.py
# meta developer: @yourname

from .. import loader, utils


@loader.tds
class HelloMod(loader.Module):
    """Первый модуль"""

    strings = {
        "name": "Hello",
        "greet": "👋 Привет, {}!",
    }
    strings_ru = {
        "greet": "👋 Здравствуй, {}!",
        "_cls_doc": "Первый модуль",
        "_cmd_doc_hello": "Поздороваться",
    }

    @loader.command(alias="hi")
    async def hello(self, message):
        name = (await message.get_sender()).first_name
        await utils.answer(message, self.strings("greet").format(name))

Сохраните файл, отправьте себе в чат и ответьте на него .lm. Команда .hello сразу работает.

Декораторы

ДекораторНазначение
@loader.command()обычная команда. Принимает alias/aliases
@loader.watcher()реагирует на все сообщения. Фильтры: only_pm, only_groups, no_media, out…
@loader.inline_handler()ответ на inline-запрос вашего бота
@loader.callback_handler()обработка нажатий на кнопки

Проблемы и FAQ

Самые частые грабли и что с ними делать.

Бот не реагирует на команды

Проверьте по порядку: процесс жив (screen -r или systemctl status), правильный ли префикс, не попал ли чат в .blacklist. Команда должна быть в вашем собственном сообщении, а не в чужом.

Не ставятся зависимости / ошибка сборки Pillow

Не хватает системных библиотек. Для Debian/Ubuntu:

sudo apt install -y build-essential python3-dev \
  libjpeg-dev zlib1g-dev libwebp-dev libffi-dev
Пишет, что нельзя запускаться от root

Сделайте отдельного пользователя — это правильный путь. Если нет выбора — python3 -m elys --root или touch force_insecure.

Команды работают, но кнопок нет

Не создался или сломался inline-бот. Перевыпустите токен в @BotFather и привяжите: .ch_bot_token <token>. У @BotFather есть лимит на 20 ботов — удалите лишние.

FloodWait и блокировки

Какой-то модуль штурмует API. Посмотрите .logs error, отключите кандидата через .togglemod. Никогда не выключайте .api_fw_protection насовсем.

Можно ли держать юзербот на телефоне

Технически да — через UserLAnd или Termux. Но Android агрессивно убивает фоновые процессы. Как песочница — нормально, как постоянный дом — нет.

Модули с Hikka и Heroku подойдут

В большинстве случаев да: есть слой совместимости и импорты hikkatl/herokutl подменяются автоматически. Модули, лезущие в внутренности ядра, могут отказать.

Забыл префикс или выключил важную команду

Самый надёжный вариант — восстановиться из бэкапа (.restoredb). Если бэкапа нет — остановите бота и почистите ключ в файле базы в корне проекта.

Как снести всё начисто

Из Telegram: .uninstall_elys. С сервера: остановить процесс, rm -rf ~/Elys, и отозвать сессию в Настройки → Устройства.
